# EventBookingApp
This is a straightforward one-page website created with.NET 9 and Umbraco CMS. 
Users can view events, view event details, and fill out a form to reserve a spot at an event via the website. 
A backend database table contains the booking information,
which is validated to avoid duplicate bookings and make sure the event isn't full.

Prerequisites 
Download Visual Studio 
Install .Net 9.0 SDK
Install umbraco template by running this in your cdm dotnet new install Umbraco.Templates::13.7.2
Optionally, download sqllite db 

Project Flow
Clone the this repository via https://github.com/Davebenshahu/EventBookingApp
Ensure you have .NET 9 installed. Restore the required NuGet packages: dotnet restore
Run the project 
Then Register with your email to access the pages in the project.
